Data Sources

This project integrates Team3 project input files with authoritative external identifiers and literature links. Each source below is mapped to the corresponding project files or fields.

  • Project-provided curated condensate annotation files — supplied to the project through the external supervisor / IRIS Kinetics: condensates.csv, protein2cdcode_v2.1.csv, proteins.csv, condensatopathies.csv, and c-mods.csv.
  • UniProtKB/Swiss-Prot reviewed human kinase query — source for uniprot_human_reviewed_kinases_raw.xlsx; query basis: reviewed human proteins, organism 9606, kinase keyword KW-0418.
  • PubMed / NCBI literature records — source resolver for PMID evidence fields from condensatopathies.csv and c-mods.csv, normalized into publication and evidence relationship tables.
  • Processed database import — sql/condensatedb.sql is the Team3 processed schema/data import artifact generated from the files above for the Bioed MariaDB deployment.

1. Sign in

  • Open the current Team3 sign-in page: Sign in to CondensateDB.
  • Select the correct role before signing in: User for query access or Administrator for admin management.

2. Search and query data

  • Proteins / Kinases / Condensates / Diseases: search by gene name, UniProt accession, condensate name, disease, or keyword.
  • Advanced Search: combine protein keywords with condensate, disease, chemical modifier, and publication filters.
  • Integrated Query: access chemical modifier queries, literature evidence, charts, and the network graph from one page.

3. Interactive Network Graph

  • Click Network Graph on the portal navigation bar or from the Integrated Query section.
  • Use the keyword box to search proteins, condensates, diseases, chemical modifiers, or PubMed IDs.
  • Select a relation type and graph limit, then click Load Graph.
  • Click any node or edge to view details in the right-side panel.
